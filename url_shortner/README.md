# ShortLink

A URL shortening service built with FastAPI, PostgreSQL, and Redis.

## Features

- User authentication
- URL shortening
- Public URL redirects
- Redis caching
- Token bucket rate limiting
- PostgreSQL persistence

## Tech Stack

- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Redis
- Pydantic
- JWT
